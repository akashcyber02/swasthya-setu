This directory contains profile pictures for the Developer / SIH 2026 Team.

How to add your team's photos:
1. Copy or save photos here with simple filenames:
   - akash.jpg (or akash.png)
   - honey.jpg
   - chandan.jpg
   - member4.jpg
   - member5.jpg
   - member6.jpg

2. Open `src/data/teamData.ts` and set:
   photoUrl: '/team/akash.jpg' (or online URL like GitHub / LinkedIn image)

3. If no photo is provided or if the file name is not found, the website will automatically display a high-resolution initials avatar badge.
